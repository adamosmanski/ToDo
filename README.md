## Instalacja i uruchomienie

1. Sklonuj repozytorium  
   git clone https://github.com/adamosmanski/ToDo.git
   cd ToDo
2. Przejdź do katalogu backendu i uruchom projekt
   cd ToDo.Backend
   dotnet restore
   dotnet run
3. Przejdź do katalogu frontendu i uruchom frontend
   cd ../ToDo.Frontend/ToDo.View
   npm install
   npm start
